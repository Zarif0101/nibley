# Limits

## Simple idea
A limit asks what value a function is heading towards as x gets closer and closer to a point, even if it never lands there. Walk towards a door: your distance gets close to zero. A function can have a limit where it has a gap.

## Key formulas
- lim (x→a) f(x) = L. a: the x-value approached, L: the value f(x) heads towards
- Hole example: (x² − 1)/(x − 1) = x + 1 when x ≠ 1, so the limit at x = 1 is 2
- Smooth functions: the limit as x→a is just f(a)

## Common mistakes
- Thinking the limit equals f(a): the function can be undefined there.
- Plugging in and getting 0/0, then giving up: factorise and cancel first.
- Checking only one side: both sides must head to the same value.

## Check questions
1. What is the limit as x→2 of x²?
   Answer: 4.
2. What is the limit as x→1 of (x² − 1)/(x − 1)?
   Answer: Cancel to x + 1, so the limit is 2.
3. Why can a limit exist where f(a) is undefined?
   Answer: The limit looks at values near a, not at a itself.

## Flashcards
Q: What does a limit describe?
A: The value f(x) approaches as x gets close to a point.
Q: Does the limit need f(a) to exist?
A: No.
Q: What do you try when you get 0/0?
A: Factorise and cancel.
Q: How many sides must agree for the limit to exist?
A: Both: left and right.
Q: Write the limit symbol for x approaching 3.
A: lim (x→3) f(x).

## Root check
- functions: If f(x) = x² + 1, what is f(3)? Answer: 10.
