# What a program is

## Simple idea
A program is a recipe for a computer: exact steps, done one at a time, top to bottom. Like a recipe card, it only works if every step is clear, because the computer never guesses what you meant. It does exactly what you wrote, even when that's not what you wanted.

## Common mistakes
- Expecting the computer to understand what you meant: it follows only what you wrote.
- Thinking steps can run in any order: they run top to bottom unless the code says otherwise.
- Thinking one typo is harmless: a single wrong character can stop the whole program.

## Check questions
1. What does a computer do with a program?
   Answer: Follows its steps exactly, one at a time, in order.
2. Why must every step be exact?
   Answer: The computer can't guess what you meant.
3. Which runs first: the top line or the bottom line?
   Answer: The top line, unless the code jumps somewhere else.

## Flashcards
Q: What is a program?
A: A list of exact steps for a computer to follow.
Q: In what order do steps normally run?
A: Top to bottom, one at a time.
Q: Does a computer guess what you meant?
A: No, it does exactly what you wrote.
Q: What is a bug?
A: A mistake in a program that makes it do the wrong thing.
Q: What is code?
A: The written instructions of a program.
