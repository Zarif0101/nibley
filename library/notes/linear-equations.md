# Linear equations

## Simple idea
Picture a balance scale that is level. Add or remove the same weight on both pans and it stays level. To solve x + 3 = 7, take 3 from both sides, so x = 4. Undo each step with its opposite: undo + with −, undo × with ÷.

## Key formulas
- ax + b = c gives x = (c − b) ÷ a. a, b, c: known numbers (a is not 0), x: the unknown
- Check: put your answer back into the equation

## Picture it
Draw `scale-balance`. Label `scale-balance.left-pan` "x + 3" and `scale-balance.right-pan` "7".
Label `scale-balance.pivot` "do the same to both sides".

## Common mistakes
- Changing only one side: whatever you do, do it to both sides.
- Adding when you should undo by subtracting: x + 3 = 7 needs − 3.
- Forgetting to divide everything: 2x + 4 = 10 gives 2x = 6, then x = 3.

## Check questions
1. What undoes "+ 3"?
   Answer: Subtract 3.
2. Solve 3x − 2 = 10.
   Answer: x = 4.
3. Why must you do the same thing to both sides?
   Answer: It keeps the two sides equal, like keeping the scale level.

## Flashcards
Q: How do you undo multiplying by 5?
A: Divide by 5.
Q: Solve x + 5 = 12.
A: x = 7.
Q: Solve 2x = 10.
A: x = 5.
Q: Solve x ÷ 3 = 4.
A: x = 12.
Q: How do you check an answer?
A: Put it back into the original equation.
