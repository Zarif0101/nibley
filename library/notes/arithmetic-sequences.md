# Arithmetic sequences and series

## Simple idea
An arithmetic sequence goes up (or down) by the same amount each step, like climbing stairs of equal height. That fixed amount is the common difference. A series is what you get when you add the terms up. Pair first with last: every pair gives the same total.

## Key formulas
- aₙ = a + (n − 1)d. aₙ: the nth term, a: first term, n: term number, d: common difference
- Sₙ = (n/2)(2a + (n − 1)d). Sₙ: sum of the first n terms
- Sₙ = (n/2)(a + l). l: last term

## Picture it
Draw `staircase`. Label `staircase.step-1` "a", `staircase.step-2` "a + d", `staircase.step-3` "a + 2d".
Add a small arrow between two steps labelled "+d each time". Label `staircase.step-5` "a + 4d".

## Common mistakes
- Using n instead of n − 1 in the nth term formula: the first term has no d added.
- Finding d by dividing: d is the later term minus the earlier term.
- Forgetting negative d for a falling sequence.

## Check questions
1. Find the 10th term of 3, 7, 11, 15, ...
   Answer: 3 + 9 × 4 = 39.
2. Find the sum of the first 5 terms of 2, 4, 6, 8, 10.
   Answer: 30.
3. Why does adding 1 to 100 give the same total as 2 to 99?
   Answer: Each pair adds to 101, so 50 pairs make 5050.

## Flashcards
Q: What is the common difference?
A: The fixed amount added to get from one term to the next.
Q: Formula for the nth term?
A: aₙ = a + (n − 1)d.
Q: Formula for the sum of n terms?
A: Sₙ = (n/2)(2a + (n − 1)d).
Q: Sum of n terms using the first and last term?
A: Sₙ = (n/2)(a + l).
Q: What is d for 20, 17, 14, ...?
A: −3.
