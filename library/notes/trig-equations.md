# Solving trig equations

## Simple idea
Solving sin x = 0.5 means finding every angle whose sine is 0.5. The sine wave hits the height 0.5 more than once per cycle, so there are usually two answers in one turn. Find the first angle with your calculator, then use the wave's symmetry to find the second.

## Key formulas
- sin x = k: x = α or x = 180° − α (α = first calculator answer)
- cos x = k: x = α or x = 360° − α
- tan x = k: x = α or x = α + 180°
- Repeats: add 360° (2π radians) to sin and cos answers for more solutions

## Picture it
Draw `graph-sine`. Draw a dashed flat line at height half of `graph-sine.peak`, labelled "y = 0.5".
Mark both places where the dashed line meets the curve with dots, labelled "first answer" and "second answer". Label `graph-sine.period-end` "360°".

## Common mistakes
- Giving only the calculator answer: look for the second angle in the range.
- Dividing both sides by sin x: it loses answers, so factorise instead.
- Using the wrong range: check if the question says degrees or radians, and the interval.

## Check questions
1. Solve sin x = 1/2 for 0° ≤ x ≤ 360°.
   Answer: x = 30° or 150°.
2. Solve tan x = 1 for 0° ≤ x ≤ 360°.
   Answer: x = 45° or 225°.
3. Why does cos x = 1/2 have two answers between 0° and 360°?
   Answer: The cosine wave reaches 1/2 once going down and once coming up: 60° and 300°.

## Flashcards
Q: Second solution of sin x = k, given first answer α?
A: 180° − α.
Q: Second solution of cos x = k, given first answer α?
A: 360° − α.
Q: Second solution of tan x = k, given first answer α?
A: α + 180°.
Q: How often do sin and cos solutions repeat?
A: Every 360° (2π radians).
Q: How do you solve 2sin²x = sin x?
A: Move everything over and factorise: sin x (2 sin x − 1) = 0.

## Root check
- trig-identities: What does sin²θ + cos²θ equal? Answer: 1.
- quadratics: Solve x² − 5x + 6 = 0. Answer: x = 2 or x = 3.
