# Algebra basics

## Simple idea
A letter stands for a number you do not know yet. If one pencil costs p pence, then 3 pencils cost 3p. That one rule works whatever p is. Terms with the same letter can be joined: 2p + 3p = 5p, like 2 apples plus 3 apples.

## Key formulas
- 3p means 3 × p. p: the price of one pencil (pence)
- 2x + 3x = 5x. x: any number
- x · x = x²
- a(b + c) = ab + ac. a, b, c: any numbers

## Common mistakes
- Writing 2x + 3 = 5x: only like terms join, so 2x + 3 stays as it is.
- Reading 3x as 3 + x: it means 3 × x.
- Writing x + x = x²: it is 2x. Squaring needs multiplying.

## Check questions
1. What does 5y mean?
   Answer: 5 times y.
2. If x = 3, what is 2x + 1?
   Answer: 7.
3. Why can you not add 2x and 3?
   Answer: One is lots of x and the other is a plain number, different kinds.

## Flashcards
Q: What is 4a + 2a?
A: 6a.
Q: What is x + x?
A: 2x.
Q: What is 3(x + 2)?
A: 3x + 6.
Q: What does a letter stand for in algebra?
A: A number that can change or is not known yet.
Q: How do you write a × b?
A: ab.
