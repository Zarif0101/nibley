# Input and output

## Simple idea
Programs talk with the world through input and output, like a vending machine: you press buttons (input) and a snack comes out (output). In code, input can be typed text, a file or a click; output can be printed text, a picture or a saved file.

## Key formulas
- Python: name = input("Name? ") reads text; print("Hi", name) shows text.

## Picture it
Draw `function-box` with `function-box.input` labelled "typed text" and `function-box.output` labelled "printed result". Draw `terminal` underneath.

## Common mistakes
- Forgetting that input() gives text, so numbers must be converted with int().
- Thinking print returns a value: it only shows text.
- Expecting input to arrive without the program asking for it.

## Check questions
1. What type does input() give in Python?
   Answer: A string.
2. How do you show "Done" on the screen?
   Answer: print("Done").
3. Name one kind of output other than text.
   Answer: A saved file, a picture or a sound.

## Flashcards
Q: What is input?
A: Data that goes into a program.
Q: What is output?
A: What a program gives back or shows.
Q: Which Python function shows text?
A: print().
Q: Which Python function reads typed text?
A: input().
Q: How do you turn typed "5" into a number?
A: int(input()).

## Root check
- what-is-a-program: Does a computer guess what you meant? Answer: No, it follows exactly what you wrote.
