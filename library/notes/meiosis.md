# Meiosis

## Simple idea
Meiosis makes sex cells (eggs and sperm). A normal body cell divides twice and ends with four cells, each with half the chromosomes. Each one is different, like four shuffled hands from one deck. When egg and sperm join, the full number is back.

## Key formulas
- 1 cell with 46 chromosomes → 4 cells, each with 23 chromosomes
- egg (23) + sperm (23) → zygote (46)

## Picture it
Draw `chromosome`. Label `chromosome.centromere`: "copied chromosome". Arrow from `chromosome.arm-top-left` to the left and from `chromosome.arm-top-right` to the right, labelled "pulled apart, twice".

## Common mistakes
- Saying meiosis makes identical cells: they are all different.
- Mixing up the number of cells: mitosis makes 2, meiosis makes 4.
- Forgetting the halving: sex cells must have half so the baby gets the full number.

## Check questions
1. How many cells does meiosis make from one cell?
   Answer: Four.
2. A cell has 8 chromosomes. How many does each sex cell have?
   Answer: 4.
3. Why must sex cells have only half the chromosomes?
   Answer: So the joined egg and sperm have the full number, not double.

## Flashcards
Q: What does meiosis make?
A: Four genetically different cells with half the chromosomes.
Q: Where does meiosis happen in humans?
A: In the testes and ovaries.
Q: What is a zygote?
A: The first cell made when an egg and a sperm join.
Q: How many chromosomes are in a human sex cell?
A: 23.
Q: Why does meiosis give variety?
A: Chromosomes are shuffled, so each sex cell is different.

## Root check
- mitosis: How many cells does mitosis make, and are they identical? Answer: Two, and yes they are identical.
