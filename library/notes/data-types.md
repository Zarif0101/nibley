# Data types

## Simple idea
Values come in kinds, like containers for different things: a jar for soup, a box for toys. Whole numbers (int), decimals (float), text (string) and true or false (boolean) are different kinds. Mixing kinds can fail: "3" + 4 can't add text to a number, just like soup in a paper bag.

## Key formulas
- Common types: int (7), float (7.5), string ("hi"), boolean (True or False).

## Picture it
Draw `jars`. Label `jars.jar-1`: "int", `jars.jar-2`: "string", `jars.jar-3`: "boolean".

## Common mistakes
- Treating "7" (text) and 7 (number) as the same.
- Expecting 7 / 2 to give 3 in every language: many give 3.5.
- Forgetting that input from the keyboard usually arrives as text.

## Check questions
1. What type is "42"?
   Answer: A string, because of the quotes.
2. What type is True?
   Answer: A boolean.
3. Why can "3" + 4 fail?
   Answer: It mixes text with a number.

## Flashcards
Q: What is a data type?
A: The kind of value, like number or text.
Q: What is a float?
A: A number with a decimal point.
Q: What is a string?
A: Text, written in quotes.
Q: What values can a boolean have?
A: True or False.
Q: How do you turn "5" into the number 5 in Python?
A: int("5").

## Root check
- variables-values: x = 4, then x = 9. What is x? Answer: 9.
