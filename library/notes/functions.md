# Functions, domain and range

## Simple idea
A function is a machine. You put a number in, a rule works on it, and one number comes out. Put 4 into "double it and add 3" and you always get 11. The inputs you are allowed are the domain. The outputs you can get are the range.

## Key formulas
- y = f(x). x: input, f: the rule, y: output
- Domain: all allowed x values. Range: all possible y values
- Vertical line test: a graph is a function if no vertical line hits it twice
- f(x) = x²: domain all x, range y ≥ 0

## Picture it
Draw `axes`. Label `axes.x-end`: "input x" and `axes.y-end`: "output f(x)".
Draw `graph-parabola`. Label `graph-parabola.vertex`: "lowest output", and `graph-parabola.arm-right`: "any x allowed".

## Common mistakes
- Thinking one input can give two outputs: a function gives exactly one.
- Dividing by zero: for f(x) = 1/x, leave out x = 0.
- Mixing up domain and range: domain is inputs (x), range is outputs (y).

## Check questions
1. If f(x) = 2x + 3, what is f(4)?
   Answer: 11.
2. What is the domain of f(x) = 1/x?
   Answer: All x except 0.
3. Why does a circle fail the vertical line test?
   Answer: A vertical line can hit it twice, so one x gives two outputs.

## Flashcards
Q: What is a function?
A: A rule that gives exactly one output for each input.
Q: What is the domain?
A: The set of allowed inputs.
Q: What is the range?
A: The set of outputs the function can give.
Q: What does f(3) mean?
A: The output when x is 3.
Q: What is the range of f(x) = x²?
A: y ≥ 0.

## Root check
- algebra-basics: If y = 2x + 1, what is y when x = 3? Answer: 7.
- coordinates: In the point (2, 5), how far across and how far up? Answer: 2 across, 5 up.
