# Standing waves

## Simple idea
Shake a skipping rope fixed at one end at just the right rate and it settles into loops that seem to stand still. Waves travel along and bounce back, and the two waves overlap. Some points never move (nodes) and some swing the most (antinodes). This is how a guitar string makes its notes.

## Key formulas
- λ = 2L / n. λ: wavelength (m), L: string length between fixed ends (m), n: number of loops (1, 2, 3...)
- f = n·v / (2L). f: frequency (Hz), v: wave speed on the string (m/s)
- Distance from one node to the next = λ / 2

## Picture it
Draw `standing-wave`. Label `standing-wave.node-1` and `standing-wave.node-2` "node: no movement".
Label `standing-wave.antinode-1` "antinode: biggest swing".

## Common mistakes
- Mixing nodes and antinodes: nodes stay still, antinodes swing most.
- Thinking one loop is one wavelength: one loop is half a wavelength.
- Thinking the wave moves along: the pattern stays put.

## Check questions
1. What is the wavelength of the first pattern (one loop) on a 1.5 m string?
   Answer: λ = 2L = 3 m.
2. A 1 m string has wave speed 100 m/s. What is its lowest frequency?
   Answer: f = 100 / (2 × 1) = 50 Hz.
3. Why do nodes form at the fixed ends?
   Answer: The ends cannot move, so the waves always cancel there.

## Flashcards
Q: What is a node?
A: A point that never moves.
Q: What is an antinode?
A: A point that swings the most.
Q: How are standing waves made?
A: Two waves travelling opposite ways overlap.
Q: Distance between neighbouring nodes?
A: Half a wavelength.
Q: Where are nodes on a string fixed at both ends?
A: At both ends.

## Root check
- superposition: A 2 cm crest meets a 2 cm trough. What is the result? Answer: 0 cm.
