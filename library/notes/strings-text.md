# Strings (text)

## Simple idea
A string is text in quotes, like "hello". It's a row of characters, each in its own numbered slot, like letters on a train with numbered seats starting at 0. You can join strings with +, take pieces out by position, and ask how long they are.

## Key formulas
- len("cat") is 3; "cat"[0] is "c"; "ab" + "cd" is "abcd".

## Picture it
Draw `array-boxes`. Label `array-boxes.cell-first`: "h (0)", `array-boxes.row`: "hello".

## Common mistakes
- Counting positions from 1: the first character is position 0.
- Adding a number to a string without converting it.
- Forgetting the quotes, so the word is read as a variable name.

## Check questions
1. What is len("code")?
   Answer: 4.
2. What is "code"[0]?
   Answer: "c".
3. What is "4" + "2"?
   Answer: "42", joined text.

## Flashcards
Q: What is a string?
A: Text, a row of characters in quotes.
Q: What does + do to two strings?
A: Joins them.
Q: What position is the first character?
A: 0.
Q: What does len() give for a string?
A: The number of characters.
Q: Is "7" a number or a string?
A: A string.
