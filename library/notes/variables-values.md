# Variables and values

## Simple idea
A variable is a name tag stuck on a value, like a tag on a lunch box with "score" written on it. Write score = 10 and the tag "score" now sits on 10. Write score = 12 and the tag moves to 12. One tag sits on one value at a time.

## Key formulas
- name = value means "put the tag name on this value"; the right side is worked out first.

## Picture it
Draw `name-tag`. Label `name-tag.write-here`: "score". Arrow from `name-tag.string-end` to a box labelled "10".

## Common mistakes
- Thinking x = 5 then x = 7 means x holds both: it now holds only 7.
- Reading = as "is equal to" like in maths: in code it means "now stands for".
- Using a variable before giving it a value.

## Check questions
1. x = 5, then x = 7. What is x?
   Answer: 7.
2. What happens first in total = 3 + 4?
   Answer: 3 + 4 is worked out, then the name total goes on 7.
3. Is count = count + 1 wrong in code?
   Answer: No, it means count is now one more than before.

## Flashcards
Q: What is a variable?
A: A name that refers to a value.
Q: What does = do in most programming languages?
A: Gives a name to a value (assignment).
Q: Can one variable hold two values at once?
A: No, only its latest value.
Q: What does x = x + 1 do?
A: Makes x one bigger.
Q: Which side of = is worked out first?
A: The right side.

## Root check
- what-is-a-program: In what order do the lines of a program run? Answer: Top to bottom, one at a time.
