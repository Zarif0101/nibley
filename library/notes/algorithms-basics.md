# Algorithms

## Simple idea
An algorithm is a clear method that always finishes, like a recipe or directions to a friend's house. Finding the biggest number in a list is an algorithm: look at each number, remember the biggest so far, and at the end you have the answer. Good algorithms are correct first, then fast.

## Key formulas
- none

## Picture it
Draw `flow-steps`. Label `flow-steps.step-1`: "look at next item", `flow-steps.step-2`: "bigger? remember it", `flow-steps.step-3`: "done: answer".

## Common mistakes
- Steps that are vague, like "find it", that a computer can't follow.
- Forgetting the case where the list is empty.
- Making it fast before making it correct.

## Check questions
1. What makes something an algorithm?
   Answer: Clear steps that always finish and solve the problem.
2. How do you find the biggest number in a list?
   Answer: Check each number, keep the biggest seen so far.
3. Why test with an empty list?
   Answer: Edge cases often break algorithms.

## Flashcards
Q: What is an algorithm?
A: A step-by-step method to solve a problem.
Q: Must an algorithm finish?
A: Yes.
Q: What is an edge case?
A: An unusual input, like an empty list.
Q: What comes first: correct or fast?
A: Correct.
Q: Is a recipe an algorithm?
A: Yes, if every step is clear and it ends.

## Root check
- loops: When does a while loop stop? Answer: When its condition becomes False.
- conditionals: With if, elif and else, how many branches run? Answer: One.
