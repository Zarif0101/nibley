# Booleans and comparisons

## Simple idea
A comparison asks a yes-or-no question and gets True or False back, like a light switch that is only on or off. age >= 18 is True for 20 and False for 15. These True and False values are called booleans, and they decide which way a program goes.

## Key formulas
- == equal to, != not equal, <, >, <=, >=.
- and (both true), or (at least one true), not (flips it).

## Picture it
Draw `light-switch`. Label `light-switch.on`: "True", `light-switch.off`: "False".

## Common mistakes
- Using = (assign) when you mean == (compare).
- Thinking or means exactly one: True or True is True.
- Comparing text and numbers, like "5" == 5, which is False in Python.

## Check questions
1. What is 3 > 5?
   Answer: False.
2. What is True and False?
   Answer: False.
3. Which symbol checks equality?
   Answer: ==

## Flashcards
Q: What is a boolean?
A: A value that is True or False.
Q: What does != mean?
A: Not equal to.
Q: When is A and B true?
A: Only when both are true.
Q: When is A or B true?
A: When at least one is true.
Q: What does not True give?
A: False.
