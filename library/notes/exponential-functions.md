# Exponential functions

## Simple idea
In an exponential, the number multiplies by the same factor every step. Bacteria doubling every hour is the classic case: 1, 2, 4, 8, 16. It starts slowly, then races upward. If the factor is below 1, it shrinks instead, like a bouncing ball losing height each bounce.

## Key formulas
- y = a·bˣ. y: output, a: starting value (when x = 0), b: growth factor, x: number of steps
- b > 1: growth. 0 < b < 1: decay
- The graph never goes below the x-axis and never touches it

## Common mistakes
- Mixing up x² and 2ˣ: in 2ˣ the variable is the power, and it grows far faster.
- Adding instead of multiplying: doubling three times gives ×8, not +6.
- Forgetting that b⁰ = 1, so the graph starts at a when x = 0.

## Check questions
1. If y = 2ˣ, what is y when x = 3?
   Answer: 8.
2. 100 bacteria double every hour. How many after 3 hours?
   Answer: 800.
3. Why is 2ˣ never negative?
   Answer: A positive number to any power stays positive.

## Flashcards
Q: What is the form of an exponential function?
A: y = a·bˣ.
Q: What does b > 1 mean?
A: Growth: the quantity multiplies by more than 1 each step.
Q: What does 0 < b < 1 mean?
A: Decay: the quantity shrinks each step.
Q: Where does y = 3ˣ cross the y-axis?
A: At y = 1.
Q: Does an exponential graph ever touch the x-axis?
A: No, it gets closer and closer.

## Root check
- indices-surds: What is 2⁻²? Answer: 1/4.
- functions: If f(x) = 3x, what is f(2)? Answer: 6.
