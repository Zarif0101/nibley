# Functions in code

## Simple idea
A function is a recipe card you write once and use many times. You give it a name, the ingredients it needs (parameters), and the steps. Calling it runs the steps; return hands back the result, like a vending machine giving you a snack for your coin and button press.

## Key formulas
- def area(w, h): return w * h  then area(3, 4) gives 12.
- Parameters are the names in the definition; arguments are the values you pass in.

## Picture it
Draw `function-box`. Label `function-box.input`: "w = 3, h = 4", `function-box.box`: "area", `function-box.output`: "12". Draw `recipe-card` beside it.

## Common mistakes
- Defining a function and never calling it.
- Printing inside instead of returning, so the result can't be used.
- Passing arguments in the wrong order.

## Check questions
1. def double(n): return n * 2. What is double(5)?
   Answer: 10.
2. What is the difference between a parameter and an argument?
   Answer: A parameter is the name in the definition; an argument is the value passed in.
3. What does return do?
   Answer: Sends a value back to where the function was called.

## Flashcards

A: A named, reusable block of code.
Q: What does it mean to call a function?
A: To run it.
Q: What are parameters?
A: The inputs a function expects.
Q: What does return do?
A: Gives a result back to the caller.
Q: Why use functions?
A: To reuse steps and keep code tidy.
