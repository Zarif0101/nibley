# Mutations

## Simple idea
A mutation is a change in the order of DNA bases, like a typo in a recipe. Sometimes the typo changes nothing. Sometimes it changes one ingredient, so the protein works badly. Rarely it makes the protein work better. Mutations in egg or sperm cells can be passed to children.

## Key formulas
- Substitution: one base swapped for another (ATG → ACG)
- Insertion or deletion: a base added or lost, so the reading frame shifts
- Mutation → changed mRNA → changed protein (maybe)

## Picture it
Draw `dna-helix`. Circle one rung at `dna-helix.base-pair` and label it "one base changed". Arrow from `dna-helix.bottom` labelled "protein may change".

## Common mistakes
- Thinking all mutations are harmful: most are harmless, a few help.
- Thinking body-cell mutations are inherited: only those in sperm or egg cells pass on.
- Thinking a swapped base always changes the protein: the code has repeats, so it may not.

## Check questions
1. What is a mutation?
   Answer: A change in the DNA base sequence.
2. A base is deleted from a gene. Why is this often worse than a swap?
   Answer: It shifts every codon after it.
3. Name one thing that can cause a mutation.
   Answer: UV light, radiation, certain chemicals, or copying errors.

## Flashcards
Q: What is a substitution mutation?
A: One base is swapped for another.
Q: What is a frameshift?
A: A base added or lost shifts all later codons.
Q: Are most mutations harmful, harmless or helpful?
A: Most are harmless.
Q: Which mutations can be inherited?
A: Those in sperm or egg cells.
Q: Name a disease caused by a gene mutation.
A: Sickle cell anaemia.

## Root check
- protein-synthesis: How many mRNA bases make one codon? Answer: Three.
