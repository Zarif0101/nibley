# Sine and cosine rules

## Simple idea
SOH CAH TOA only works in right-angled triangles. For any other triangle you need two new rules. The sine rule links each side to the angle facing it. The cosine rule is Pythagoras with a fix-up term, for when you know two sides and the angle between them, or all three sides.

## Key formulas
- a / sin A = b / sin B = c / sin C. a, b, c: sides (cm or m), A, B, C: the angle opposite each side
- a² = b² + c² − 2bc·cos A. Same units as above
- Area = ½·a·b·sin C. C: angle between sides a and b (area in cm² or m²)

## Picture it
Draw `triangle`. Label corners `triangle.vertex-a`, `triangle.vertex-b`, `triangle.vertex-c` "A", "B", "C". Label the side opposite A at `triangle.side-bc-mid` "a", and the others "b" at `triangle.side-ca-mid` and "c" at `triangle.side-ab-mid`.
Mark angle A at `triangle.angle-a` "A faces a".

## Common mistakes
- Pairing a side with the wrong angle: side a faces angle A.
- Forgetting the cosine rule has a minus: a² = b² + c² − 2bc·cos A.
- Using the sine rule with no side-and-opposite-angle pair known: use the cosine rule.

## Check questions
1. A = 30°, a = 5, B = 90°. Use the sine rule to find b.
   Answer: 5 / 0.5 = b / 1, so b = 10.
2. b = 3, c = 4, A = 90°. Use the cosine rule to find a.
   Answer: a² = 9 + 16 − 0 = 25, so a = 5.
3. Why does the cosine rule give Pythagoras when A = 90°?
   Answer: cos 90° = 0, so the last term disappears.

## Flashcards
Q: Write the sine rule.
A: a / sin A = b / sin B = c / sin C.
Q: Write the cosine rule for side a.
A: a² = b² + c² − 2bc·cos A.
Q: When do you use the cosine rule?
A: Two sides and the angle between, or all three sides.
Q: Write the area of a triangle using two sides.
A: Area = ½·a·b·sin C.
Q: Which side does angle A face?
A: Side a.

## Root check
- trig-ratios: A right triangle has hypotenuse 10 and an angle of 30°. How long is the side opposite it? Answer: 10 × sin 30° = 5.
