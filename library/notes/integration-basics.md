# Integration as reverse differentiation

## Simple idea
Differentiating gives you a slope. Integrating goes backwards: you are given the slope and you find the function it came from. It is like knowing how fast a plant grows each day and working out how tall it is. Many functions share one slope, so we add a constant C.

## Key formulas
- ∫xⁿ dx = xⁿ⁺¹/(n+1) + C, for n ≠ −1. x: the variable, n: a fixed number, C: any constant (no unit needed)
- ∫k dx = kx + C. k: a fixed number
- ∫cos x dx = sin x + C and ∫sin x dx = −cos x + C. x: angle in radians (rad)

## Common mistakes
- Forgetting + C: always add it on an indefinite integral.
- Raising the power but not dividing by it: ∫x² dx is x³/3, not x³.
- Mixing up the sign of sin and cos: ∫sin x dx = −cos x + C.

## Check questions
1. What is ∫3x² dx?
   Answer: x³ + C.
2. What is ∫4 dx?
   Answer: 4x + C.
3. Why do we add C?
   Answer: A constant disappears when you differentiate, so many functions have the same slope.
